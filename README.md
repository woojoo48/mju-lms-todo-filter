# 명지대 LMS 할 일 필터

명지대학교 LMS(`lms.mju.ac.kr`)의 **할 일 숫자와 목록에서 비교과·비정규 프로그램을 숨기고, 정규 과목 기준으로 다시 보여 주는** Chrome 확장 프로그램입니다.

> [!IMPORTANT]
> 명지대학교가 만든 공식 도구가 아닙니다. 개인이 만든 비공식 확장입니다.
> **공식 배포처는 이 저장소의 [Releases](../../releases)뿐입니다.** 다른 곳에서 받은 파일은 설치하지 마세요.
> 설치한 뒤에는 아래 **⚠️ 반드시 확인해 주세요** 항목을 꼭 한 번 해 주세요.

## 왜 만들었나요

LMS 홈 화면의 할 일 숫자에는 정규 수업 과제와 함께 비교과 특강, 경진대회, 안내 강좌 같은 프로그램의 과제도 모두 들어갑니다.

예를 들어 할 일이 **50개**로 보이는데, 실제 수강 중인 정규 과목의 할 일은 **6개**뿐일 수 있습니다. 그러면 급한 수업 과제가 목록에 묻히고, 숫자도 실제 해야 할 양을 보여 주지 못합니다.

이 확장은 LMS 서버나 데이터를 건드리지 않습니다. 내 브라우저 화면에서만 숫자와 목록을 정규 과목 기준으로 바꿉니다.

편하게 LMS를 쓰려고 만든 확장이니, 필요한 분은 자유롭게 설치해 쓰세요. 🙂

## 기능

- **상단 할 일 배지와 오른쪽 "할일 N" 숫자**를 정규 과목 기준으로 바꿉니다. 할 일 창을 열지 않아도 바로 바뀝니다.
- **할 일 창**에서 비교과 과목의 탭과 카드를 숨기고, 영상·과제·설문 숫자를 다시 셉니다.
- **오른쪽 미리보기**에서 비교과 과제 카드를 숨깁니다.
- **자동 분류**: 정규 과목은 표시하고, 비교과·비정규 프로그램은 숨깁니다.
- **과목별 수동 설정**: 팝업에서 과목마다 `자동 / 항상 표시 / 숨기기`를 고를 수 있습니다.
- **전환 버튼**: 오른쪽 할 일 제목 옆과 할 일 창 위의 버튼으로 `전체 보기 ↔ 정규만 보기`를 바로 바꿉니다.
- **안전장치**: 받은 목록이 LMS 숫자와 맞지 않으면 필터를 적용하지 않고 원래 화면을 그대로 보여 줍니다. 그래서 과제가 몰래 빠지는 일이 없습니다.

## 설치

데스크톱 Chrome에서만 사용할 수 있습니다.

1. [Releases](../../releases)에서 최신 `mju-lms-todo-filter.zip`을 받습니다.
   - Release 설명에 적힌 SHA-256 값과 받은 파일의 값이 같은지 확인하면 더 안전합니다.
   - Windows PowerShell: `Get-FileHash .\mju-lms-todo-filter.zip -Algorithm SHA256`
2. 압축을 풉니다. `manifest.json`이 들어 있는 폴더를 지우거나 옮기지 말고 그대로 둡니다.
3. Chrome 주소창에 `chrome://extensions`를 입력하고 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드**를 누르고 압축을 푼 폴더를 선택합니다.
5. LMS 탭이 열려 있었다면 새로고침합니다.

### 업데이트

새 zip을 받아 **같은 폴더에 덮어쓴 뒤**, `chrome://extensions`에서 이 확장 카드의 새로고침 버튼을 누릅니다. 그다음 LMS 탭을 새로고침합니다.

## ⚠️ 반드시 확인해 주세요

데이터 누락을 막는 검증 로직을 넣어 두었습니다. 그래도 혹시 모를 오류에 대비해, **처음 설치했을 때 한 번** 아래 내용을 꼭 확인해 주세요.

1. 확장을 설치한 뒤 LMS에 접속합니다.
2. Chrome 오른쪽 위의 확장 프로그램 아이콘(퍼즐 모양)을 누르고 이 확장을 엽니다.
3. 팝업 위쪽 문구가 `정규 과목만 표시 중 · N / 전체 M`인지 확인합니다.
   - 숫자가 맞지 않아 보류되면 그 이유가 대신 나옵니다. 이때는 LMS 원래 화면이 그대로 보입니다.
4. 과목 목록에서 **수강 중인 정규 과목이 모두 `자동 · 정규(표시)`로 되어 있는지** 확인합니다.
   - `자동 · 비교과(숨김)` 쪽에 정규 과목이 섞여 있지 않은지도 봅니다.
   - 현재 할 일이 있는 과목만 목록에 나옵니다.
5. 잘못 숨겨진 정규 과목이 있으면 그 과목을 **항상 표시**로 바꿉니다. 바꾸면 바로 반영됩니다.
6. 할 일 창 위의 **전체 보기** 버튼을 눌러 원래 목록과 한 번 비교해 보면 더 확실합니다.

**정규 교과목이 누락되지 않았는지 확인한 뒤 사용해 주세요!**

## 사용법

- 설치하면 **정규 과목만 표시**가 기본으로 켜져 있습니다. LMS를 열면 바로 적용됩니다.
- 끄고 켜기: 오른쪽 할 일 제목 옆 버튼, 할 일 창 위 버튼, 또는 확장 팝업의 스위치를 씁니다.
- 분류 바꾸기: Chrome 툴바의 퍼즐 아이콘에서 이 확장을 열고, 과목마다 표시 방식을 고릅니다. 고르면 바로 저장되고 LMS 화면에 반영됩니다.
- 팝업 위쪽에 현재 상태가 나옵니다.
  - 예: `정규 과목만 표시 중 · 6 / 전체 50`
  - 필터가 보류되면 그 이유가 나옵니다.

## 동작 방식

1. LMS 페이지가 열리면 LMS가 할 일 창에서 쓰는 것과 같은 요청 두 개를 보냅니다.
   - `todo_list.acl`: 전체 할 일
   - `todo_list_count.acl`: 전체 개수
2. 할 일마다 붙어 있는 **LMS 과목 키**로 과목을 구분합니다.
   - `A…`로 시작하면 정규 과목으로 보고 표시합니다.
   - `N…`로 시작하면 비교과·비정규 프로그램으로 보고 숨깁니다.
   - 그 밖의 키는 판단하지 않고 표시합니다.
3. 받은 할 일 수가 LMS 전체 개수와 같을 때만 숫자와 목록을 바꿉니다.
4. 주기적으로 요청하지 않습니다. LMS 숫자가 바뀔 때만 한 번 다시 확인합니다.

## 권한과 개인정보

- 실행 범위는 `https://lms.mju.ac.kr/ilos/*`뿐입니다. 요청하는 권한은 `storage` 하나입니다.
- 이 브라우저(`chrome.storage.local`)에 저장하는 것: 과목 키, 과목명, 과목별 할 일 수, 표시 설정, 상태 문구
- **저장하지 않는 것**: 과제 제목, 마감일, 계정 정보
- **외부 서버로 보내는 데이터는 없습니다.** 요청은 모두 LMS 자신(`lms.mju.ac.kr`)에게만 보내고, 로그인된 내 세션으로 내 할 일만 읽습니다.
- 코드는 이 저장소에 모두 공개되어 있습니다. 빌드 단계나 외부 라이브러리가 없습니다.

## 알려진 한계

- **자동 분류 규칙(`A` 정규 / `N` 비교과)은 한 학기 과목으로 확인한 규칙입니다.** 정규 수업인데 숨겨지는 과목이 있으면 팝업에서 "항상 표시"로 바꿔 주세요.
- **할 일이 99개를 넘으면** LMS가 상단 배지를 99로 잘라 보여 줍니다. 확장도 같은 규칙을 따릅니다. 이때 과제를 하나 끝내도 배지가 계속 99라서, 새로고침하기 전까지는 정규 과목 숫자 반영이 늦을 수 있습니다.
- **오른쪽 미리보기**는 LMS가 마감 순으로 5개까지만 보여 줍니다. 그중 비교과 카드를 숨기면 5개보다 적게 보일 수 있습니다.
- 별도 알림(종 모양), LMS 푸시·이메일, 모바일 앱은 바꾸지 않습니다.
- **LMS 화면 구조가 바뀌면 동작하지 않을 수 있습니다.** 이때도 안전장치 때문에 원래 화면이 그대로 보입니다.
